Collaborative Filtering
Neighbourhood-based (user-user)
- User ratings act as a user representation; no need feature engineering
- Use vector distance metrics to determine similar users (KNN)
- look for the items that each nearest neighbor likes
- compute a score for each item, sort by score

Neighbourhood-based (item-item) michael
- Each item is represented by the users that liked it
- Use vector distance metrics to determine similar items
- For an item i, check each user's liked items and compare similarity to item i
- Take weighted average of similarity * rating to predict user's score for item i
